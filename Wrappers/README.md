# Wrappers

AbstractNFFTs implementations around other NFFT libraries: [FINUFFT](FINUFFT.jl),
[NFFT3](NFFT3.jl) and [ducc0](DUCC0.jl), each an independent package in this repository.

They implement the interface of AbstractNFFTs 0.x and have not yet been ported to
AbstractNFFTs 1.0 (the development version on this branch); their released versions work with
NFFT.jl 0.14.
